01 type / const
TypeScriptでの意味

type はオブジェクトの「形」を定義する設計図です。
const は一度決めたら変えられない定数です。

Minecraftで例えると

type = クラフトレシピ（設計図）
素材が揃っていないとクラフトできない！

const = ガラスケースに飾ったアイテム
触れない・交換できない。

図：レシピ → クラフト → アイテム
TypeScript コード
type Item = {
  name: string;
  count: number;
};

const sword: Item = {
  name:  "ダイヤの剣",
  count: 1,
};

sword = { name: "鉄の剣", count: 1 }; // ❌ constは上書き不可
sword.count = 2;                     // ✅ 中身の変更はOK
02 オプショナル（?）
TypeScriptでの意味

? をつけると「あってもなくてもOK」な
プロパティになります。
値は string または undefined になります。

Minecraftで例えると

レシピのオプション素材（染料など）。
なくてもクラフトできるけど、
あると色が変わる！

enchantedSword → エンチャントあり
normalSword → エンチャントなし。でも両方作れる。

図：必須素材 vs オプション素材
TypeScript コード
type Item = {
  name:   string;
  count:  number;
  enchant?: string; // ? = あってもなくてもOK
};

const enchantedSword: Item = {
  name:    "ダイヤの剣",
  count:   1,
  enchant: "シャープネスV", // ✅ あり
};

const normalSword: Item = {
  name:  "鉄の剣",
  count: 1,
  // enchant なし → OK!
};
03 readonly
TypeScriptでの意味

readonly をつけると、
読むことはできるが書き換えられない
プロパティになります。

Minecraftで例えると

アイテムの特定スロットに鍵がかかっている状態。
name スロット → 🔒 鍵あり（変更不可）
age スロット  → 🔓 鍵なし（変更可）

ガラスケース（const）は箱ごと触れないが、
readonly は「そのスロットだけ」ロック！

図：readonlyスロットのイメージ
TypeScript コード
type Item = {
  readonly name: string; // 🔒 変更不可
  durability: number;           // 🔓 変更可
};

const diamondPickaxe: Item = { name: "ダイヤのツルハシ", durability: 1561 };

diamondPickaxe.name       = "鉄のツルハシ"; // ❌ readonly なので不可
diamondPickaxe.durability = 1000;           // ✅ OK
04 const vs readonly
TypeScriptでの意味

似ているけど守る範囲が違います。
const → 変数自体を再代入不可
readonly → そのプロパティを書き換え不可

Minecraftで例えると

const = ガラスケース
→ アイテム（箱ごと）を別のものに
   交換できない

readonly = スロットの鍵
→ その枠だけ書き換えられない
   他の枠は自由

操作 const readonly
変数ごと上書き
sword = {...}		 ❌ 不可 ✅ 可
中身の書き換え
sword.name = "..."		 ✅ 可 ❌ 不可
違いを確認するコード
// const だけの場合
const sword = { name: "ダイヤの剣", durability: 1561 };
sword = { name: "鉄の剣", durability: 250 }; // ❌ 箱ごとは無理
sword.durability = 1000;                      // ✅ 中身はOK

// readonly だけの場合
type P = { readonly name: string };
let sword: P = { name: "ダイヤの剣" };
sword = { name: "鉄の剣" };  // ✅ letなので箱ごとはOK
sword.name = "鉄の剣";       // ❌ nameスロットは不可
05 関数
TypeScriptでの意味

値を受け取って、加工して、返す処理のまとまりです。
function またはアロー関数 => で定義します。
返す値がない場合は void を使います。

Minecraftで例えると

関数 = 自動クラフト機械⚙️
素材（引数）を入れると加工して
結果（返り値）を出してくれる。

void = 音を鳴らすだけの機械
動くけど何も出てこない。

図：関数の仕組み
TypeScript コード
// ① functionを使った書き方
function craftSword(count: number): number {
  return count * 2;
}

// ② アロー関数（同じ意味）
const craftSword = (count: number): number => {
  return count * 2;
};

// ③ 型をtypeで定義して使い回す
type CraftFunc = (count: number) => number;

const craftSword: CraftFunc = (count) => count * 2; // 剣は素材2倍
const craftBow:   CraftFunc = (count) => count * 3; // 弓は素材3倍

// ④ voidは何も返さない
const spawnPlayer = (): void => {
  console.log("プレイヤーがスポーンしました！");
};

// ⑤ 型推論（返り値の型を省略できる）
const craft = (count: number) => count * 2; // ✅ TypeScriptが推論
パーツ 意味 Minecraftで例えると
引数 (count: number) 受け取る値 投入口に入れる素材
返り値 : number 返す値の型 出口から出るもの
void 何も返さない 音を鳴らすだけの機械
型推論 型を自動判断 素材から結果を自動判断
